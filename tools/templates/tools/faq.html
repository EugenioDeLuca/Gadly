{% trans "General" %}

{% trans "What is Gadly?" %}

{% blocktrans %}Gadly is a collection of free online utilities for text editing, social media, finance, web/SEO, file management, and more. All tools run in your browser—no installation required.{% endblocktrans %}

{% trans "Is my data safe?" %}

{% blocktrans %}Most tools process data locally in your browser or send it only for the specific operation (e.g., translation, meta tag check). We do not store or log your personal data. For sensitive content, always check the privacy policy.{% endblocktrans %}

{% trans "Does it work on mobile?" %}

{% blocktrans %}Yes! The site is responsive and optimized for smartphones and tablets. You can use all tools from your mobile device.{% endblocktrans %}

{% trans "Are Gadly tools free?" %}

{% blocktrans trimmed %}Yes. The utilities on this site are free for typical personal and work use. Technical limits (such as maximum file size) depend on the specific tool and are shown when relevant.{% endblocktrans %}

{% trans "Account and Access" %}

{% trans "Do I need an account to use Gadly?" %}

{% blocktrans %}No. Most tools are available immediately without registration. If a tool or feature requires login, you will see a clear message before continuing.{% endblocktrans %}

{% trans "I forgot my password. What can I do?" %}

{% blocktrans %}Use the password reset option on the login page. If your email is verified, you can reset your password and access your account again.{% endblocktrans %}

{% trans "Can I change my username or profile image?" %}

{% blocktrans %}Yes. Open your account profile from the header menu and update your username, email, and avatar from there.{% endblocktrans %}

{% trans "Usage and Results" %}

{% trans "Why is a result different from another website?" %}

{% blocktrans %}Some tools use different rules, formulas, or rounding methods depending on implementation. If you need strict precision (for legal or accounting use), always verify with your official reference.{% endblocktrans %}

{% trans "Why does a tool return an error with a URL?" %}

{% blocktrans %}The URL may be blocked, invalid, or unavailable from the server side. Check that it starts with http/https, that the page is public, and that the domain is reachable.{% endblocktrans %}

{% trans "Can I use these tools for work or clients?" %}

{% blocktrans %}Yes, but always review the output before publishing or delivering it. Gadly helps speed up work, but final validation is your responsibility.{% endblocktrans %}

{% trans "Site and preferences" %}

{% trans "Can I use dark mode or a warm color theme?" %}

{% blocktrans trimmed %}Yes. Use the theme and warm-tone controls in the site header. Your choices are saved in the browser so the look stays the same on your next visit.{% endblocktrans %}
